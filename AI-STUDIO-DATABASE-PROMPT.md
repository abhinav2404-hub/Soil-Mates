# 🧠 AI Studio Database Integration Prompt & Implementation Specification

## System Context
You are working on **Soil Mates** — a production-ready, full-stack agricultural marketplace platform built for Google AI Studio Build mode, Docker, and Cloud Run.

---

## 1. Core Database Directive
1. **Never Fail Hard on Database Disconnection**:
   In AI Studio preview containers, a local MongoDB daemon may not be active unless externally configured or spun up in a container.
   The application **must always implement a Resilient Hybrid Data Access Layer**:
   - Primary: Mongoose ODM connecting to `process.env.MONGODB_URI`.
   - Fallback: Pre-seeded in-memory store in `server/src/models/store.ts` that provides full CRUD persistence across user sessions.
   - The application must boot immediately without hanging or throwing uncaught connection errors.

2. **Schema & Model Structure**:
   Models are declared centrally in `server/src/db/models.ts` and `server/src/models/`:
   - `User` (`FARMER`, `BUYER`, `VENDOR`, `ADMIN`)
   - `Product` (Agricultural commodities with quantity, price, grade, organic status)
   - `Order` (Farmgate checkout with server-side price recalculation and escrow state)
   - `CropDiagnosis` (Pathology results generated by Gemini AI)
   - `MarketRate` (APMC mandi prices and 7-day trend history)
   - `Review` (Verified buyer reviews and ratings)
   - `Notification` (Transactional and agronomic alerts)
   - `FarmProfile` & `VendorProfile`

3. **Index Management**:
   All collection indexes are defined in `server/src/db/indexes.ts` and executed safely via `ensureIndexes()`.

4. **Database Seeding**:
   Seeding logic is contained in `server/src/db/seed.ts` and triggered on startup if the collections are empty.
   Seed data includes authentic Indian agricultural produce:
   - Sehore Sharbati Wheat (MP)
   - Nashik Red Onions (Maharashtra)
   - Vidisha Desi Tomatoes (MP)
   - Ujjain Yellow Soybean (MP)
   - Chambal Black Mustard (MP)
   - Indore Firm Potatoes (MP)
   - Guntur Sun-Dried Red Chillies (AP)
   - Palak Spinach (Bhopal Rural)

---

## 2. Server-Side Gemini AI Integration
- All Gemini calls **must remain on the server side** (`server/src/services/geminiService.ts`).
- Uses the official `@google/genai` TypeScript SDK:
  ```typescript
  import { GoogleGenAI, Type } from '@google/genai';
  const ai = new GoogleGenAI({
    apiKey: process.env.GEMINI_API_KEY,
    httpOptions: { headers: { 'User-Agent': 'aistudio-build' } }
  });
  ```
- Default model: `gemini-flash-latest`.
- Returns structured JSON adhering to the `DiagnosisOutput` interface with an agronomic decision-support disclaimer.

---

## 3. Order Security & Financial Validation
- **Never trust client-calculated totals**:
  The Express controller `server/src/controllers/orderController.ts` recalculates line item totals using the database price, checks inventory availability, and deducts ordered quantities atomically.
